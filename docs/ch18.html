Chapter 18

Portal 跳出 DOM 层级

模态框、下拉菜单、提示气泡都有同一个麻烦：祖先的 overflow: hidden 和 z-index 会把它们裁掉。Portal 就是为此存在的。

chapter18/portaldemo/src/Modal.js · ModalWithoutPortal.js · SideBarHelp.js · public/index.html

原书清单在做什么

public/index.html 在 #root 之外额外准备了 #sidebar 和 #modal 两个空容器； Modal.js 用 ReactDOM.createPortal(jsx, document.getElementById("modal")) 把弹窗的 DOM 送过去。 对比 ModalWithoutPortal.js 就能看出差别。

React 19 · Modal.tsx
import { createPortal } from "react-dom";
import { useEffect, useRef, type ReactNode } from "react";

export default function Modal({ title, isOpen, onClose, children }: {
  title: string; isOpen: boolean;
  onClose: () => void; children: ReactNode;
}) {
  const dialogRef = useRef<HTMLDialogElement>(null);

  useEffect(() => {
    const d = dialogRef.current;
    if (!d) return;
    if (isOpen) d.showModal();   // 原生 dialog：自带焦点陷阱和 Esc
    else d.close();
  }, [isOpen]);

  return createPortal(
    <dialog ref={dialogRef} onClose={onClose} aria-label={title}>
      <h1>{title}</h1>
      {children}
    </dialog>,
    document.getElementById("modal")!,
  );
}

// 用法：Modal 写在 App 里，DOM 落在 #modal
// <Modal title="…" isOpen={open} onClose={() => setOpen(false)}>
//   <p>…</p>
// </Modal>
Vue 3 · Modal.vue（Teleport）
<script setup lang="ts">
import { ref, watch, useTemplateRef } from "vue";

const props = defineProps<{ title: string; isOpen: boolean }>();
const emit = defineEmits<{ close: [] }>();

const dialog = useTemplateRef<HTMLDialogElement>("dialog");

watch(() => props.isOpen, (open) => {
  open ? dialog.value?.showModal() : dialog.value?.close();
});
</script>

<template>
  <!-- Teleport 就是 Vue 的 Portal，内置指令，无需 import -->
  <Teleport to="#modal">
    <dialog ref="dialog" :aria-label="title" @close="emit('close')">
      <h1>{{ title }}</h1>
      <slot />
    </dialog>
  </Teleport>
</template>
小结
  • Portal / Teleport 只改变 DOM 落点，不改变组件树关系。
  • 因此事件仍沿 React 树冒泡，Context 仍能读到。
  • 典型场景：模态框、Toast、Tooltip、被 overflow 裁切的下拉菜单。
  • 能用原生 <dialog> 就用，它免费送你焦点管理和 Esc 关闭。
