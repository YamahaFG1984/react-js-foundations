Chapter 09

Ref：渲染之外的盒子

state 是"会引起重画的数据"，ref 是"跨渲染活着、但不引起重画的盒子"。两句话就能分清它们。

chapter09/CreateRefClass.js · CreateRefFunction.js · TextReader.js · TextReaderCallback.js · AudioPlayer.js · ScrollToDemo.js

原书清单在做什么

原书演示了三代 ref 写法：字符串 ref（已废弃）、回调 ref（TextReaderCallback.js）、 React.createRef()（class）/ useRef()（函数）。用途都一样：拿到真实 DOM 节点， 好调用 focus()、play()、scrollTo() 这些 React 不管的命令式 API。

React 19 · TextReader.tsx
import { useEffect, useRef } from "react";

export default function TextReader({ text }: { text: string }) {
  const textView = useRef<HTMLTextAreaElement>(null);

  // 相当于原书的 componentDidMount
  useEffect(() => {
    textView.current?.focus();
  }, []);

  return (
    <textarea
      ref={textView}
      defaultValue={text}
      style={{ width: 380, height: 400 }}
    />
  );
}

// 滚动到某个元素（原书 ScrollToDemo.js）
function scrollTo(el: HTMLElement | null) {
  el?.scrollIntoView({ behavior: "smooth" });
}
Vue 3 · TextReader.vue
<script setup lang="ts">
import { onMounted, useTemplateRef } from "vue";

defineProps<{ text: string }>();

// 名字要和模板里的 ref="textView" 一致
const textView = useTemplateRef<HTMLTextAreaElement>("textView");

onMounted(() => {
  textView.value?.focus();
});

function scrollTo(el: HTMLElement | null) {
  el?.scrollIntoView({ behavior: "smooth" });
}
</script>

<template>
  <textarea
    ref="textView"
    :value="text"
    style="width: 380px; height: 400px"
  />
</template>
"ref" 这个词在两边指的不是一回事

Vue 的 ref() 是响应式状态，最接近 React 的 useState； Vue 的模板 ref="x" 才是 React 的 useRef + DOM 引用。 而 React 的 useRef 用来存"不触发渲染的可变值"时，Vue 侧的对应物是一个普通变量——不需要任何 API。

React 19：ref 可以直接当 prop 传了

React 19 · 不再需要 forwardRef
// React 18 及以前：必须 forwardRef 包一层
// const Input = forwardRef((props, ref) => <input ref={ref} />);

// React 19：ref 就是一个普通 prop
function MyInput({ ref, ...rest }: {
  ref?: React.Ref<HTMLInputElement>;
} & React.ComponentProps<"input">) {
  return <input ref={ref} {...rest} />;
}

function Parent() {
  const inputRef = useRef<HTMLInputElement>(null);
  return <MyInput ref={inputRef} placeholder="hi" />;
}

// 想只暴露特定方法（原书 CountingBox.js 的 useImperativeHandle）
function CountingBox({ ref }: { ref?: React.Ref<{ count: number }> }) {
  const [text, setText] = useState("");
  useImperativeHandle(ref, () => ({
    count: text.trim().split(/\s+/).filter(Boolean).length,
  }), [text]);
  return <textarea value={text}
    onChange={(e) => setText(e.target.value)} />;
}
Vue 3 · defineExpose
<!-- MyInput.vue：子组件默认对父组件封闭 -->
<script setup lang="ts">
import { ref, useTemplateRef } from "vue";

const text = ref("");
const count = computed(
  () => text.value.trim().split(/\s+/).filter(Boolean).length
);

// 明确声明对外暴露什么，其余一律不可见
defineExpose({ count });
</script>

<template>
  <textarea v-model="text" />
</template>

<!-- 父组件 -->
<script setup lang="ts">
const box = useTemplateRef<{ count: number }>("box");
function report() { console.log(box.value?.count); }
</script>
<template>
  <MyInput ref="box" />
  <button @click="report">count words</button>
</template>
小结
  • useRef = 跨渲染保持同一个对象 + 改它不触发渲染。
  • 用途一：拿 DOM 节点做命令式操作；用途二：存不该引起重绘的可变值。
  • React 19 起 ref 是普通 prop，forwardRef 可以不写了。
  • Vue 的 ref() ≈ React 的 useState；Vue 的模板 ref="x" ≈ React 的 DOM ref。
