Chapter 08

受控与非受控表单

"受控"这个词吓人，机制其实只有一个闭环。看懂这个环，也就看懂了 Vue 的 v-model 是什么糖。

chapter08/Uncontrolled1.js · Controlled1–4.js · SearchForm/ · BlogComment.js · SizeSelect.js · SignUpForm.js

原书清单在做什么

Controlled1.js 是个反面教材：<input value="" /> 写死了 value 又没有 onChange， 于是输入框完全打不动字——这恰好证明了受控组件里 DOM 只是 state 的投影。 Controlled2.js 补上 onChange 才让它活过来。

React 19 · SignUp.tsx（受控）
import { useState } from "react";

export default function SignUp() {
  const [email, setEmail] = useState("");

  return (
    <form>
      <label>
        Enter your email address:
        <input
          type="email"
          value={email}
          // 中途改写输入：全部转小写
          onChange={(e) => setEmail(e.target.value.toLowerCase())}
        />
      </label>
      <p>Your email address: {email}</p>
    </form>
  );
}
Vue 3 · SignUp.vue
<script setup lang="ts">
import { ref } from "vue";
const email = ref("");
</script>

<template>
  <form>
    <label>
      Enter your email address:
      <!-- v-model 自带 .trim / .number / .lazy 修饰符 -->
      <input type="email" v-model.trim="email" />
    </label>
    <p>Your email address: {{ email }}</p>
  </form>
</template>

非受控：值留在 DOM 里，提交时读一次

React 19 · BlogComment.tsx
import { useState, useRef, type FormEvent } from "react";

export default function BlogComment() {
  const [comments, setComments] = useState<string[]>([]);
  const textAreaRef = useRef<HTMLTextAreaElement>(null);

  function recordComment(e: FormEvent) {
    e.preventDefault();
    const v = textAreaRef.current?.value ?? "";
    if (v) setComments([...comments, v]);
  }

  return (
    <form onSubmit={recordComment}>
      <textarea ref={textAreaRef} defaultValue="" />
      <button>Submit</button>
      {/* 只在末尾追加、项本身无状态 —— 这种列表用下标当 key 才安全，见「补 A」 */}
      {comments.map((c, i) => <p key={i}>{c}</p>)}
    </form>
  );
}
Vue 3 · BlogComment.vue
<script setup lang="ts">
import { ref, useTemplateRef } from "vue";

const comments = ref<string[]>([]);
// Vue 3.5+ 推荐 useTemplateRef
const box = useTemplateRef<HTMLTextAreaElement>("box");

function recordComment() {
  const v = box.value?.value ?? "";
  if (v) comments.value.push(v);
}
</script>

<template>
  <form @submit.prevent="recordComment">
    <textarea ref="box" />
    <button>Submit</button>
    <p v-for="(c, i) in comments" :key="i">{{ c }}</p>
  </form>
</template>
React 19 新增：Form Actions

原书用 onSubmit + preventDefault 手工处理提交。React 19 给 <form> 加了 action 属性：传一个函数进去，React 自动阻止默认行为、把表单数据打包成 FormData、 在提交期间维护 pending 状态、提交完成后重置表单。配套的 useActionState 把 "待处理 / 结果 / 错误"三件事收进一个 Hook。

React 19 · 用 Action 重写提交
import { useActionState } from "react";
import { useFormStatus } from "react-dom";

async function subscribe(prev: string | null, formData: FormData) {
  const email = String(formData.get("email") ?? "");
  if (!email.includes("@")) return "请填写有效邮箱";
  await fetch("/api/subscribe", { method: "POST", body: formData });
  return "订阅成功";
}

function SubmitButton() {
  const { pending } = useFormStatus();   // 读所在 form 的状态
  return <button disabled={pending}>
    {pending ? "提交中…" : "Sign Up"}
  </button>;
}

export default function SignUpForm() {
  const [message, formAction] = useActionState(subscribe, null);
  return (
    <form action={formAction}>
      <input name="email" type="email" />
      <SubmitButton />
      {message && <p>{message}</p>}
    </form>
  );
}
Vue 3 · 手写等价逻辑
<script setup lang="ts">
import { ref } from "vue";

const email = ref("");
const pending = ref(false);
const message = ref<string | null>(null);

// Vue 没有内置 Action 概念，pending 自己管
async function subscribe() {
  if (!email.value.includes("@")) {
    message.value = "请填写有效邮箱";
    return;
  }
  pending.value = true;
  try {
    await fetch("/api/subscribe", {
      method: "POST",
      body: JSON.stringify({ email: email.value }),
    });
    message.value = "订阅成功";
    email.value = "";
  } finally {
    pending.value = false;
  }
}
</script>

<template>
  <form @submit.prevent="subscribe">
    <input v-model="email" type="email" />
    <button :disabled="pending">
      {{ pending ? "提交中…" : "Sign Up" }}
    </button>
    <p v-if="message">{{ message }}</p>
  </form>
</template>
小结
  • 受控 = value 下行 + onChange 上行的闭环；缺一条边输入框就会失灵。
  • 非受控 = 值留在 DOM，用 ref 读；适合文件上传、第三方组件、只在提交时才关心值的场景。
  • v-model 就是这个闭环的两条边被编译器补齐了。
  • React 19 的 <form action> + useActionState + useFormStatus 把提交态标准化了，值得直接上手。
