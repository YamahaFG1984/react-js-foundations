Chapter 01

从 createElement 到 DOM

本章唯一要弄懂的事：你写的标签，经过哪几道手，才变成屏幕上的元素。

chapter01/Listing0101.html · HelloWorld.js · Listing0103.js

原书清单在做什么

第一个例子用两个 <script> 从 CDN 引入 react 和 react-dom，然后手写 React.createElement—— 故意不用 JSX，好让你看见 JSX 底下是什么：

// chapter01/HelloWorld.js —— 原书写法
class HelloWorld extends React.Component {
  constructor(props) {
    super(props);
    this.state = { personName: "World" };
  }
  render() {
    return React.createElement("h1", null, "Hello, " + this.state.personName);
  }
}
ReactDOM.render(React.createElement(HelloWorld), document.querySelector("#app"));

这段代码今天已经跑不起来了：ReactDOM.render 在 React 18 被移除。但它揭示的管线一个字都没变。

React 19 重写

React 19 · main.tsx
import { createRoot } from "react-dom/client";
import { useState } from "react";

function HelloWorld() {
  const [name, setName] = useState("World");
  return (
    <>
      <h1>Hello {name}</h1>
      <input
        value={name}
        onChange={(e) => setName(e.target.value)}
      />
    </>
  );
}

// 注意：不再是 ReactDOM.render
createRoot(document.getElementById("app")!)
  .render(<HelloWorld />);
Vue 3 · main.ts + App.vue
// main.ts
import { createApp } from "vue";
import App from "./App.vue";
createApp(App).mount("#app");

<!-- App.vue -->
<script setup lang="ts">
import { ref } from "vue";
const name = ref("World");
</script>

<template>
  <h1>Hello {{ name }}</h1>
  <input v-model="name" />
</template>
三个已经变了的细节

① 不用再写 import React from "react"——React 17 起的新 JSX transform 由编译器自动引入 jsx()。 ② createRoot 返回的 root 可以 .unmount()，同一个页面能挂多个 root。 ③ 服务端渲染出来的页面用 hydrateRoot，不是 createRoot。

小结
  • JSX 是语法糖，编译后就是函数调用；React Element 是普通不可变对象。
  • Fiber 是运行时的可变结构，Hooks 的数据就存在这里。
  • Vue 模板同样被编译，两者都没有"运行时解析字符串模板"这回事。
