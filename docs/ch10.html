Chapter 10

样式与作用域

React 本身对 CSS 没有任何主张。所以这一章真正在讨论的问题只有一个：怎么让一个组件的样式不泄漏到别处。

chapter10/WarningMessage.js · messageStyles.js · CSSModule.js · my-component.module.css · ExampleStyled.js · StyledParent.js

原书清单在做什么

StyledParent.js 里注释掉的那行 import './style.css' 是本章的题眼：把它取消注释， style.css 里的 p { font-size: 80px } 会影响整个应用的每一个 <p>， 不管它在哪个组件里。这就是 CSS 的全局性问题。四种方案分别在不同阶段解决它：

React 19 · CSS Modules + CSS 变量
/* Message.module.css */
.message { padding: 6px; border-radius: 3px;
  color: var(--fg); background: var(--bg); }

// Message.tsx
import styles from "./Message.module.css";

type Kind = "warning" | "info" | "success";

const palette: Record<Kind, { fg: string; bg: string }> = {
  warning: { fg: "#fff", bg: "#b3261e" },
  info:    { fg: "#111", bg: "#e8eaed" },
  success: { fg: "#fff", bg: "#1b5e20" },
};

export default function Message(
  { kind = "info", text }: { kind?: Kind; text: string }
) {
  const c = palette[kind];
  return (
    <p
      className={styles.message}
      style={{ "--fg": c.fg, "--bg": c.bg } as React.CSSProperties}
    >{text}</p>
  );
}
Vue 3 · scoped + v-bind() in CSS
<script setup lang="ts">
import { computed } from "vue";

type Kind = "warning" | "info" | "success";
const { kind = "info", text } = defineProps<{
  kind?: Kind; text: string;
}>();

const palette = {
  warning: { fg: "#fff", bg: "#b3261e" },
  info:    { fg: "#111", bg: "#e8eaed" },
  success: { fg: "#fff", bg: "#1b5e20" },
};
const c = computed(() => palette[kind]);
</script>

<template>
  <p class="message">{{ text }}</p>
</template>

<style scoped>
/* v-bind 会被编译成 CSS 变量，自动跟随响应式更新 */
.message {
  padding: 6px; border-radius: 3px;
  color: v-bind("c.fg");
  background: v-bind("c.bg");
}
</style>
小结
  • React 对 CSS 无主张，所以方案多；Vue 内置 scoped，多数项目不用选。
  • 内联 style 用对象，属性名是驼峰，数字自动补 px。
  • 优先 CSS Modules / scoped 这类构建期方案；运行时 CSS-in-JS 已不是推荐路线。
  • 动态样式交给 CSS 变量，比重新生成类名便宜得多。
