Chapter 07

合成事件与委托

你写了 1000 个 onClick，浏览器上却只装了极少数几个真实监听器。这一层抽象解释了 React 事件的所有"怪脾气"。

chapter07/EventProps.js · EventObject.js · WarningButton.js · ColorWheel*.js · CoffeeMachine.js

原书清单在做什么

EventProps.js 让你打开控制台看 SyntheticBaseEvent 长什么样；四个 ColorWheel 版本演示了 class 里 this 的四种绑定写法（构造函数 bind / 行内 bind / 箭头函数属性 / class field）。 函数组件把后一半问题整个消掉了，但合成事件本身依然存在。

React 19 · ColorWheel.tsx
import { useState, type ChangeEvent } from "react";

export default function ColorWheel() {
  const [color, setColor] = useState("#ff0000");

  // 函数组件里没有 this，也就没有 bind 问题
  function changeColor(e: ChangeEvent<HTMLInputElement>) {
    setColor(e.target.value);
  }

  return (
    <>
      <div style={{
        width: 200, height: 200, borderRadius: "50%",
        backgroundColor: color,
      }} />
      <input value={color} onChange={changeColor} />

      {/* 阻止默认行为：手动调用，没有修饰符 */}
      <a href="/x" onClick={(e) => e.preventDefault()}>不跳转</a>
    </>
  );
}
Vue 3 · ColorWheel.vue
<script setup lang="ts">
import { ref, computed } from "vue";

const color = ref("#ff0000");
const wheel = computed(() => ({
  width: "200px", height: "200px",
  borderRadius: "50%", backgroundColor: color.value,
}));
</script>

<template>
  <div :style="wheel" />
  <input v-model="color" />

  <!-- 阻止默认行为：修饰符，编译器生成包装 -->
  <a href="/x" @click.prevent>不跳转</a>
</template>
要做的事ReactVue
绑定点击onClick={fn}@click="fn"
阻止默认e.preventDefault()@click.prevent
阻止冒泡e.stopPropagation()@click.stop
只触发一次自己加标志位@click.once
捕获阶段onClickCapture@click.capture
特定按键if (e.key === "Enter")@keyup.enter
传额外参数onClick={() => fn(id)}@click="fn(id)"
拿到原生事件e.nativeEvent回调参数本身就是原生事件
小结
  • React 把事件委托到根容器；SyntheticEvent 是跨浏览器的包装。
  • 事件沿 React 组件树 传播，与 DOM 层级可以不一致。
  • 函数组件让 class 时代的 this 绑定问题彻底消失。
  • Vue 用编译期修饰符做同样的事，写起来更短，但少了"用 JS 表达一切"的一致性。
