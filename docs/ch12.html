Chapter 12

路由：URL 即状态

React 自身没有路由。React Router 做的事只有一件：把地址栏当成一份状态，按它决定渲染哪棵子树。

chapter12/（v5 写法） · chapter12-react-router-v6/NestedRoutes.js · URLParamsHook.js · NavMenu.js · UsingHistory.js

原书两份清单的差距

仓库里同时保留了 v5 和 v6 两套代码，说明这个库变化有多快。到 v7，写法又变了一次——路由从"一堆组件"变成了"一份数据结构"：

v5（原书 chapter12）v6（chapter12-react-router-v6）v7（现在）
<Switch><Routes>createBrowserRouter([...])
component={X} / render={}element={<X/>}同 v6，或用 Component: X
props.match.paramsuseParams()同 v6，且可类型化
useHistory().push()useNavigate()同 v6
<Redirect><Navigate>redirect()（在 loader 里）
exact 属性默认精确匹配同 v6
在组件里 useEffect 取数同左loader：导航前就开始取数
React Router 7 · router.tsx
import { createBrowserRouter, RouterProvider,
         Outlet, NavLink, useParams } from "react-router";

function Layout() {
  return (
    <>
      <nav>
        <NavLink to="/dashboard"
          style={({ isActive }) =>
            isActive ? { fontWeight: 700 } : undefined}>
          Dashboard
        </NavLink>
      </nav>
      <Outlet />      {/* 子路由渲染在这里 */}
    </>
  );
}

function Report() {
  const { id } = useParams();
  return <h3>Report #{id}</h3>;
}

const router = createBrowserRouter([
  {
    path: "dashboard",
    element: <Layout />,
    children: [
      { path: "reports", element: <Reports />, children: [
        { path: ":id", element: <Report />,
          // 导航开始时就取数，不用等组件挂载
          loader: ({ params }) =>
            fetch(`/api/reports/${params.id}`),
        },
      ]},
    ],
  },
]);

export default () => <RouterProvider router={router} />;
Vue Router 4 · router.ts
import { createRouter, createWebHistory } from "vue-router";

const router = createRouter({
  history: createWebHistory(),
  routes: [
    {
      path: "/dashboard",
      component: () => import("./Layout.vue"),
      children: [
        {
          path: "reports",
          component: () => import("./Reports.vue"),
          children: [
            { path: ":id", component: () => import("./Report.vue") },
          ],
        },
      ],
    },
  ],
});
export default router;

小结
  • 路由 = 把 URL 当状态；<Outlet/> / <router-view/> 是子路由的插槽。
  • v7 的 loader 把取数提前到导航阶段，避免"先渲染空壳再闪一下"。
  • 原书 v5 写法（Switch、component=、match.params）今天不要再照抄。
