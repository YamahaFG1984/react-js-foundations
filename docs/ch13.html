Chapter 13

错误边界

一个组件抛错，默认会让整个应用白屏。错误边界的作用是在树上设一道闸，把爆炸范围限制住。

chapter13/ErrorBoundary.js · ErrorBoundaryWithDidCatch.js · ErrorBoundaryWithReset.js · SampleTree.js · SampleTreeWithBoundary.js · BadComponent.js

原书清单在做什么

SampleTree.js 里的 Main 调用了一个不存在的 props.renderTheGraph，运行时抛错； SampleTreeWithBoundary.js 只是把 <Main/> 用 <ErrorBoundary> 包了一层， 结果 NavBar 和 Footer 就活下来了。

React 19 · react-error-boundary
import { ErrorBoundary } from "react-error-boundary";
import { createRoot } from "react-dom/client";

// 错误边界至今仍必须是 class（唯一还需要 class 的场景），
// 所以实践中直接用这个库，别自己写。
function Fallback({ error, resetErrorBoundary }: {
  error: Error; resetErrorBoundary: () => void;
}) {
  return (
    <div role="alert">
      <p>这块内容加载失败：{error.message}</p>
      <button onClick={resetErrorBoundary}>重试</button>
    </div>
  );
}

export default function App() {
  return (
    <>
      <NavBar />
      <ErrorBoundary
        FallbackComponent={Fallback}
        onError={(e, info) => reportToServer(e, info)}
      >
        <Main />
      </ErrorBoundary>
      <Footer />
    </>
  );
}

// React 19：根级别的兜底钩子
createRoot(document.getElementById("root")!, {
  onUncaughtError: (e, info) => reportToServer(e, info),
  onCaughtError:   (e, info) => reportToServer(e, info),
}).render(<App />);
Vue 3 · onErrorCaptured
<!-- ErrorBoundary.vue：任何组件都能当边界 -->
<script setup lang="ts">
import { ref, onErrorCaptured } from "vue";

const error = ref<Error | null>(null);

onErrorCaptured((err) => {
  error.value = err as Error;
  return false;   // 返回 false 阻止继续向上冒泡
});

function reset() { error.value = null; }
</script>

<template>
  <div v-if="error" role="alert">
    <p>这块内容加载失败：{{ error.message }}</p>
    <button @click="reset">重试</button>
  </div>
  <slot v-else />
</template>

<!-- 全局兜底 -->
<script>
// main.ts
app.config.errorHandler = (err, instance, info) => {
  reportToServer(err, info);
};
</script>
两边都捕不到异步错误

setTimeout、Promise、事件处理器里抛的错，React 的错误边界和 Vue 的 onErrorCaptured 都不管—— 因为它们不在渲染调用栈里。这类错误要么自己 try/catch 后转成 state， 要么用 window.addEventListener("unhandledrejection", …) 全局兜。

小结
  • 错误沿组件树冒泡，被最近的边界捕获，边界内的子树被换成兜底界面。
  • React 里错误边界仍需 class——直接用 react-error-boundary。
  • Vue 里任何组件加个 onErrorCaptured 就是边界，返回 false 阻止冒泡。
  • 异步错误两边都捕不到，需要单独处理。
