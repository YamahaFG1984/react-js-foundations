最后一句

这两个框架的差别，不在 API 数量，而在它们各自认为"变化"应该怎么被发现： React 说"我重算一遍再比对"，Vue 说"我记住谁依赖谁再通知"。 往回翻到导读那张图——你现在应该能把这份速查表里的每一行，都挂回那两条流水线上。
