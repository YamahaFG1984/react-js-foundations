原书代码与今天的差距

仓库里的 package.json 锁在 react@^17.0.2，所有清单都是那个年代的写法。下面这张表是本笔记统一采用的现代化替换，后面每章不再重复说明。

原书写法（2021）今天的写法（2026）为什么

class 组件 + this.setState函数组件 + Hooksclass 仍能跑，但新 API（Hooks、Suspense 集成）不再为它增加支持
PropTypes 运行时校验TypeScript 类型React 19 已从包中移除 propTypes 支持，写了也不生效
defaultProps（函数组件）参数默认值 { x = 1 }同上，React 19 对函数组件不再读取 defaultProps

全部章节

按原书章节编号排列；灰底的三篇是书里没有、但打基础必须补上的内容。

01从 createElement 到 DOM本章唯一要弄懂的事：你写的标签，经过哪几道手，才变成屏幕上的元素。 补Akey 与协调算法上一节的管线停在"协调算出差异"。这一节讲它怎么算——以及为什么 key 写错会让输入框里的内容整体错位一格。 03JSX 不是模板花括号里是 JavaScript 表达式，不是模板语法。理解这一条，本章所有"技巧"都变成常识。 04组件、children 与组合这一章原书用了大量 class 组件。今天 class 已经不是主流，但它留下的两个概念——组合与重渲染传播——一天也没过时。 06Props 与 State全书最重要的一章。原书那几个"计数器加两次却只加了一"的例子，暴露的是 React 最反直觉、也最核心的设计：状态是渲染的快照。 补B状态住在树的哪个位置上一节说 state 是"这次渲染的快照"。那这份数据究竟存在哪？答案不是"存在组件里"——是存在树中的那个位置上。 07合成事件与委托你写了 1000 个 onClick，浏览器上却只装了极少数几个真实监听器。这一层抽象解释了 React 事件的所有"怪脾气"。 08受控与非受控表单"受控"这个词吓人，机制其实只有一个闭环。看懂这个环，也就看懂了 Vue 的 v-model 是什么糖。 09Ref：渲染之外的盒子state 是"会引起重画的数据"，ref 是"跨渲染活着、但不引起重画的盒子"。两句话就能分清它们。 10样式与作用域React 本身对 CSS 没有任何主张。所以这一章真正在讨论的问题只有一个：怎么让一个组件的样式不泄漏到别处。 11Hooks 的规则从何而来"只能在顶层调用、不能放进 if 里"——这条规则听起来武断。看一眼 React 内部怎么存 Hook 数据，它就变成了唯一可能的设计。 补C大部分 useEffect 都不该存在上一章讲了 effect 怎么运转。这一节讲更要紧的事：它不该用来做什么。初学者写的 effect 里，大约七成是多余的。 12路由：URL 即状态React 自身没有路由。React Router 做的事只有一件：把地址栏当成一份状态，按它决定渲染哪棵子树。 13错误边界一个组件抛错，默认会让整个应用白屏。错误边界的作用是在树上设一道闸，把爆炸范围限制住。 15工具链：webpack → Vite原书手搭了 webpack + Babel + Jest。这条路今天没人走了，但知道每个环节在干什么，出问题时才不至于抓瞎。 16数据获取与持久化原书这一章的取数代码藏着一个所有人都会踩的 bug：请求竞态。修好它需要的正是第 11 章那个清理函数。 17Context 穿透组件树原书用同一个 Dashboard 写了三遍：逐层传 props、用 Context、用组合。这三种解法值得放在一起看——因为大多数人只学了第二种。 18Portal 跳出 DOM 层级模态框、下拉菜单、提示气泡都有同一个麻烦：祖先的 overflow: hidden 和 z-index 会把它们裁掉。Portal 就是为此存在的。 19并发特性与下一步仓库里 chapter19/index.js 是个空文件。这一节就用来补上：书出版之后，React 真正变了的那部分。 ★React ↔ Vue 速查表把全书的对照集中在一处。左列是意图，中右两列是两边的标准答案。
